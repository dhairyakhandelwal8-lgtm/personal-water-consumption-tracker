# Personal Water Consumption Tracker

A responsive, browser-based prototype for the CHE110 Environmental Studies group assignment at Lovely Professional University.

## Features
- Add water-use entries by activity, litres, date, and optional note.
- Daily and last-seven-days totals, daily average, and a simple bar chart.
- Configurable tracking goal and progress indicator.
- Recent-entry table with delete controls.
- CSV export for recorded entries.
- Practical water-conservation tips and project team details.

## Scope notes
This prototype uses user-entered estimates. It does not connect to real water meters or sensors, and it does not use AI predictions. The chart summarizes the saved entries. The daily goal is a user-defined tracking benchmark, not medical advice.
